# AV1 Software Decoder — плагин для exteraGram

Позволяет воспроизводить AV1-видео через программный декодер Android (`c2.android.av1-dav1d.decoder` или `c2.android.av1.decoder`/libgav1) на устройствах без аппаратной поддержки AV1.

Без плагина Telegram считает AV1 поддерживаемым только при наличии аппаратного декодера. В остальных случаях AV1-варианты видео отбрасываются, а если видео есть только в AV1, выбирается самое низкое качество.

## Установка

Скачайте `av1_sw_decoder.plugin` из [Releases](../../releases), отправьте его в «Избранное» в exteraGram и нажмите на файл.

## Настройки

- **Программный декодер AV1** — включение и выключение плагина.
- **Когда использовать AV1**
  - *Только если нет другого кодека* (по умолчанию): если у видео есть H.264, всё работает как в обычном Telegram. Программный AV1 включается только для видео, которые есть исключительно в AV1.
  - *Всегда, когда есть AV1*: экономит трафик, но сильнее нагружает процессор.
- **Макс. разрешение AV1** — AV1-варианты выше этого разрешения не используются (по умолчанию 1080p).
- **Предпочитать dav1d** — ставит `c2.android.av1-dav1d.decoder` раньше libgav1.
- **Сбросить флаг «AV1 не поддерживается»** — очищает `unsupport_video/av01`, который Telegram навсегда записывает после первой ошибки AV1.
- **Программный декодер для HEVC** (по умолчанию выключено) — ставит системный программный HEVC-декодер (`c2.android.hevc.decoder` / `OMX.google.hevc.decoder`) раньше аппаратного. Помогает, если HEVC-видео играет со звуком, но без картинки или с артефактами: так бывает с аппаратными декодерами некоторых SoC (например, Kirin). Аппаратный декодер остаётся в списке запасным.

## Диагностика

Плагин отправляет диагностический лог на `https://stxlvn.tech/av1log`: после загрузки, при ошибке плеера и после создания AV1-декодера. Лог можно отправить и вручную — кнопкой «Отправить лог сейчас».

В лог попадают:
- модель устройства, SoC, версия Android и приложения;
- найденные AV1- и HEVC-декодеры и статус хуков;
- выбор качеств и кодеков, ошибки плеера.

Сообщения, ссылки, пути и имена файлов из лога вырезаются. Отправку можно выключить в настройках плагина («Отправлять диагностику»).

Раздел «Диагностика» в настройках скрыт: он открывается и закрывается долгим нажатием на «Программный декодер AV1». В нём — переключатель отправки, кнопки «Отправить лог сейчас» и «Отправить сведения об SDK», а также найденные в системе декодеры и номер сессии.

## Как это работает

| Хук | Назначение |
|---|---|
| `VideoPlayer.supportsHardwareDecoder` | Для AV1 возвращает `true`, если в системе есть программный декодер |
| `VideoPlayer.getQualities` | Фильтрует AV1-варианты по выбранному режиму и ограничению разрешения |
| `MediaCodecUtil.getDecoderInfos` | Ставит программные декодеры первыми (для AV1 — dav1d раньше libgav1; для HEVC — если включён переключатель) |
| `DefaultRenderersFactory.<init>` | Включает переход на следующий декодер, если текущий не запустился |
| `VideoPlayer.onPlayerError` | При ошибке программного AV1 отключает подмену до перезапуска приложения |

Хуки на media3 необязательные: если классы не найдены, плагин продолжает работать без них и пишет об этом в лог.

## Ограничения

- Нужен **Android 10+**: в более старых версиях в системе нет программного AV1-декодера, и плагин ничего не делает.
- Программное декодирование высоких разрешений на слабых процессорах может тормозить. В этом случае снизьте «Макс. разрешение AV1».
